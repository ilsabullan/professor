# 교수자 필기 파트 작업 범위

> 담당: 교수자 화면 (강의자료 업로드, 뷰어, 필기, 저장)
> 애니메이션 생성과 마이크(음성 입력)는 애니메이션 담당 범위

## 페이지 흐름

```
[① 차시 목록] ──차시 선택──▶ [③ 필기 화면] ◀──페이지 선택── [② 모아보기]
  1차시 / 2차시 / 3차시        (자료 + 필기)   ──모아보기 버튼──▶  (전체 페이지 바둑판)
  + 새 차시(PDF 업로드)
```

| 화면 | 설명 |
|---|---|
| ① 차시 목록 | 첫 화면. 차시 카드(제목, 첫 페이지 미리보기, 마지막 수정일). "+ 새 차시"로 PDF 업로드 |
| ② 모아보기 | 차시의 전체 페이지를 필기된 상태로 바둑판 보기. 페이지를 누르면 해당 페이지로 이동. 빈 페이지 추가 |
| ③ 필기 화면 | 자료 위에 필기하는 메인 화면 |

## 기능 범위 (MVP)

| 영역 | 기능 |
|---|---|
| 차시 관리 | 차시 목록, 새 차시 만들기(PDF 업로드), 이름 바꾸기, 삭제 |
| 모아보기 | 전체 페이지 바둑판 보기, 눌러서 해당 페이지로 이동, 빈 페이지 추가 |
| 뷰어 | 페이지 넘기기, 확대/축소, 화면 이동, 발표 모드(전체화면) |
| 필기 | 펜(색·굵기), 형광펜, 지우개(획 단위), 실행 취소/다시 실행, 손바닥 무시 |
| 레이저 포인터 | 아래 "레이저 포인터 동작" 참고. 저장하지 않음 |
| 저장 | 필기만 저장(자동 저장). 차시를 다시 열면 그대로 복원 |

## 레이저 포인터 동작

| 상황 | 동작 |
|---|---|
| 펜을 대고 움직이는 동안 | 그은 궤적 전체가 화면에 남음 |
| 펜을 떼면 | 0.5초를 셈 |
| 0.5초 안에 다시 펜을 대면 | 앞 궤적은 그대로 두고 새 궤적을 이어서 그림. 0.5초는 처음부터 다시 셈 |
| 마지막으로 펜을 떼고 0.5초가 지나면 | 남은 궤적 전체가 약 0.2초 동안 서서히 흐려지며 사라짐 |
| 저장 | 저장하지 않음 |

## MVP에서 제외

| 기능 | 사유 |
|---|---|
| 이미지 업로드 | 제외 결정 (PDF만 지원) |
| 애니메이션 저장 | 필기만 저장 |
| 마이크(음성 녹음) | 애니메이션 담당 범위 |
| 애니메이션 생성 | 애니메이션 담당 범위 |
| 올가미 도구, 텍스트 상자, 부분·픽셀 지우개 | 시간이 남으면 추가 |
| 필기 검색, PDF 내보내기, 클라우드 동기화, 폴더·북마크 | 제외 |

## 애니메이션 담당과 주고받을 데이터

필기는 이미지가 아닌 획 단위 벡터로, 획마다 시간 정보를 함께 저장한다.

```ts
type Stroke = {
  id: string;
  pageId: string;
  tool: "pen" | "highlighter";
  color: string;
  width: number;
  points: { x: number; y: number; t: number; p?: number }[]; // x,y: 페이지 기준 0~1, t: ms, p: 필압
  startedAt: number; // 강의 시작 기준 ms
  endedAt: number;
};

// 필기 → 애니메이션
onStrokeEnd(stroke: Stroke)

// 레이저 포인터 → 애니메이션 (사용 여부 확인 필요)
onLaserEnd(trail: { pageId: string; points: { x: number; y: number; t: number }[] })
```

애니메이션은 필기 레이어 위의 별도 레이어에 그린다.

## 미정 사항

| 항목 | 상태 |
|---|---|
| 레이저 궤적 데이터 전달 여부 | 애니메이션 담당 확인 필요 |
| 애니메이션 레이어 구조(필기 위 빈 레이어 제공) | 애니메이션 담당 확인 필요 |
| 발표 화면 분리(학생용 화면에 도구 모음 숨김) | 추가 여부 결정 필요 (추천) |
| 도형 보정(직선·원 다듬기) | 애니메이션 담당과 상의 필요 |
| 기술 스택 | 미정 (웹 React + Canvas 추천) |
| 저장 위치 | 미정 (브라우저 저장 / 서버 저장) |
| 마감 일정 | 미정 |
